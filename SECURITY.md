# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | ✅ |
| < 1.0 | ❌ |

Security fixes land on the latest release. There are no long-term support branches.

## Reporting a vulnerability

**Do not open a public issue.**

Report privately through [GitHub Security Advisories](https://github.com/storyloom/storyloom/security/advisories/new), or email **security@storyloom.app**.

Please include:

- What the vulnerability is and where it lives
- Steps to reproduce it, or a proof of concept
- What an attacker could achieve with it
- The version and platform you tested on

### What to expect

- **Within 48 hours** — we acknowledge your report.
- **Within 7 days** — we confirm the issue and give you an assessment.
- **Within 90 days** — we aim to ship a fix and publish an advisory.

We will keep you updated as we work, and credit you in the advisory unless you would rather stay anonymous. If we disagree that a report is a vulnerability, we will explain why rather than closing it silently.

Please give us a reasonable window to ship a fix before disclosing publicly.

## Scope

This policy covers the StoryLoom application and this website.

Out of scope:

- Vulnerabilities in third-party dependencies — report those upstream, though we appreciate a heads-up
- Findings that require physical access to an unlocked machine
- Reports generated by automated scanners with no demonstrated impact
- Missing hardening headers on the static marketing site with no exploitable consequence
- Social engineering of maintainers or users

## A note on the threat model

StoryLoom is local-first. Projects are plain files on your own disk, and the shipping release has no AI layer — no model, no provider, no API key, and nothing transmitted to a server. There is no account system and no backend that holds your manuscripts.

That removes whole categories of risk, but it also means anything that reads, corrupts, or exfiltrates local project files is taken seriously. So is anything that would cause the app to make a network request the author did not ask for.
